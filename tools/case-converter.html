When you need each case format

Different contexts expect different text casing conventions. This tool converts your text into 10 formats at once, so you can grab whichever one you need:

  • camelCase and PascalCase — used for variable and class names in JavaScript, Java, and C#.
  • snake_case — the standard for Python and Ruby variable names, and common in database column names.
  • kebab-case — used in URLs, CSS class names, and file names.
  • CONSTANT_CASE — the convention for constants in most programming languages.
  • Title Case and Sentence case — for headings, article titles, and proper formatting in documents.

Frequently asked questions
